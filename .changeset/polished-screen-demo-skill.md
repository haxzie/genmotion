A new skill, **polished screen demo**: a product demo that looks screen-recorded
in a tool like Screen Studio, but is built from the real interface rather than
captured. It walks the flow in a browser, photographs each step, and puts those
screens inside a window with a synthetic cursor, push-in zooms, keystroke and
click sounds on the exact frames, and one continuous voiceover, with an optional
lip-synced presenter. Three new capabilities back it: `browse-site`,
`browse-capture` and `request-takeover`.
