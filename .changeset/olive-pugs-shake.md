Connect an integration from the chat. Name an app the agent could connect — "pull the frames from my Figma file", "a video from this month's Linear cycle" — and it searches the plugin catalog (`search_plugins`) and offers the one you meant as a callout in the transcript: what it is, what it would do here, and a Connect button that signs you in or asks for the key, the same way the Plugins tab does. A link into an app is also no longer something to photograph: `browse_page` on a Figma file only ever got a canvas that never finishes loading, so the connector is offered before the browser is opened.
